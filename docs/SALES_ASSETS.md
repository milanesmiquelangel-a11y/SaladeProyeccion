# Sales Assets — Sala de Proyección

## Purpose

Use this checklist to assemble the visual package for an acquisition listing without exposing secrets or overstating the product's current state.

## Recommended image order

### 1. Hero image

Show the main AI video studio interface on desktop.

Suggested caption:

> **AI Video Studio — Prompt → Video**
> A creator-focused interface with configurable output and multilingual narration.

### 2. Creation workflow

Show the scene prompt and the main generation controls.

Caption:

> **A structured creator workflow**
> Prompt, format, duration, quality, FPS and narration are organized in one production interface.

### 3. Output formats

Show the format selector or representative UI states for:

- 16:9
- 9:16
- 1:1

Caption:

> **Built for multiple content formats**
> Suitable for landscape, vertical and square video workflows.

### 4. Project organization

Show projects, drafts, history or templates.

Caption:

> **More than a model endpoint**
> The application includes project organization and reusable prompt workflows.

### 5. Commercial foundation

Show the account/credit interface without exposing financial secrets.

Caption:

> **Credit-based commercial foundation**
> PostgreSQL-backed credits with reservation, finalization and refund handling, plus Stripe integration points.

### 6. Architecture / handoff

Show a simple diagram or repository structure.

Caption:

> **Provider-oriented architecture**
> The application layer is separated from the video provider so the buyer can adapt infrastructure and provider strategy.

## Screenshot rules

- Never include API keys, passwords, database URLs, Stripe secrets or private tokens.
- Never include personal photos or personal account information.
- Use clean test data and neutral prompts.
- Prefer the same browser size and visual theme across screenshots.
- Crop out browser bookmarks, unrelated tabs and personal notifications.
- Do not fabricate metrics, customers, revenue or usage.

## 60-second visual sequence

1. Hero interface — 8 seconds.
2. Prompt and controls — 12 seconds.
3. Generation/output — 15 seconds.
4. Projects/history — 8 seconds.
5. Credits/billing — 7 seconds.
6. Architecture + acquisition offer — 10 seconds.

## Listing thumbnail

Use a clean hero composition with:

**SALA DE PROYECCIÓN**

**AI VIDEO STUDIO**

**PROMPT → VIDEO**

**ACQUISITION OPPORTUNITY**

**USD 7,500 · NEGOTIABLE**

Avoid putting technical claims, revenue figures or third-party provider logos in the thumbnail.

## Buyer-facing message

> A ready-to-customize AI video studio application with an implemented creator interface, prompt-to-video workflow, project organization, credit accounting, billing integration points, media processing and deployment documentation. Offered as a technology/product acquisition for USD 7,500 negotiable.
