# Buyer Demo Script — Sala de Proyección

## Goal

Present the product in approximately 60 seconds without making claims that depend on a third-party provider's future availability.

## 0–10 seconds — Product

Open the application and show the main video studio interface.

Say:

> “Sala de Proyección is an international AI video studio designed to turn a scene description into a finished short video.”

## 10–25 seconds — Creation workflow

Enter a concise scene prompt. Show the available output controls:

- 16:9, 9:16 and 1:1 formats.
- Duration selection.
- Quality selection.
- 24/30 FPS.
- Optional narration and language selection.

Say:

> “The interface is already structured like a creator product rather than a raw model endpoint.”

## 25–40 seconds — Production and media layer

Show the generation workflow and, when available in the environment, the resulting video. Show project/history organization if relevant.

Say:

> “The backend handles generation orchestration, media normalization and assembly, with optional narration.”

Do not promise a specific rendering speed, quality level or provider uptime.

## 40–50 seconds — Commercial layer

Show the account/credit experience and, if configured, the billing area.

Say:

> “The product also includes PostgreSQL-backed credit accounting with reservation, finalization and refund handling, plus Stripe Checkout/webhook integration points.”

## 50–60 seconds — Buyer value

Show the project structure/documentation or acquisition page.

Say:

> “The architecture separates the application layer from the video provider, so a buyer can adapt the provider and infrastructure strategy without rebuilding the product interface.”

Finish with:

> “The complete source code, deployment configuration and technical handoff documentation are included in the acquisition.”

## Demo rules

- Use a simple prompt that is unlikely to trigger provider moderation.
- Never expose API keys, database credentials or administrator passwords.
- If a third-party provider is unavailable during a live demo, show the interface and architecture instead of claiming the provider is guaranteed.
- Keep the demo focused on the product, not on a particular AI model.
